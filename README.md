# 自我使用说明书 · 高考志愿版

一个面向高中生专业选择与自我探索的 AI 对话网页。它通过连续情境问题、历史人物共鸣卡片和结构化总结，帮助使用者梳理核心驱动、适合发挥的环境、耗电模式，以及值得进一步了解的大学专业方向。

> 在线页面：[打开自我使用说明书](https://yusheng266186-beep.github.io/self-manual/)  
> GitHub：[查看源代码](https://github.com/yusheng266186-beep/self-manual)

## 项目定位

这个项目不是传统的分数换算或院校排名工具，而是一份偏向“认识自己”的高考志愿辅助页面。

它适合：

- 对大学专业很多，但暂时说不清自己真正喜欢什么的学生；
- 希望从具体经历和工作状态出发，而不是只做性格标签测试的人；
- 想了解专业学习难点、真实工作环境和潜在消耗点的人；
- 希望在手机上完成一轮连续、沉浸式自我探索的人。

页面输出仅用于启发和整理思路，不能替代省级招生政策、院校招生章程、专业培养方案、体检要求和正式志愿填报建议。

## 主要功能

### 连续式自我探索

- 从“做到忘记时间的事情”开始，而不是直接要求选择专业；
- 通过选项或自由输入完成多轮情境对话；
- 逐步分析核心驱动、发光条件、使用须知和已知 Bug；
- 保留当前会话上下文，让后续问题结合前面的回答继续推进。

### 历史人物共鸣

- 根据回答匹配具有代表性的历史人物；
- 展示人物经历、精神特质及与用户回答的关联；
- 提供“专业与现实”视角，避免只给抽象性格标签；
- 支持在人物卡片内进行短对话。

### 专业方向与现实图景

- 结合对话结果给出 2—3 个可继续调研的专业方向；
- 说明专业学习中可能遇到的真实困难；
- 提醒就业环境、技能迭代、工作节奏和心理消耗；
- 鼓励使用者继续核对课程设置、院校差异和个人条件。

### 结构化说明书

完成探索后生成个人说明书，包括：

- 专属称号与一句话标签；
- 核心驱动；
- 发光条件；
- 使用须知；
- 已知 Bug 与耗电模式；
- 建议调研的专业方向及现实提醒。

## 使用方式

### Android 手机

1. 使用 Chrome 或其他现代浏览器打开 Pages 地址；
2. 页面会自动进入探索界面，不需要填写 API Key 或访问码；
3. 可通过浏览器菜单选择“添加到主屏幕”，以后像普通应用一样打开。

### 在线使用

直接打开 Pages 地址即可开始探索。页面通过 DeepSeek 官方 API 生成对话。

AI 对话依赖网络连接；断网时静态页面仍可能显示，但模型回答无法生成。

### 本地预览

页面是单文件静态前端，不需要 npm 或构建工具。下载仓库后可以直接打开 index.html，也可以在仓库目录启动：

    python -m http.server 8080

然后访问：

    http://localhost:8080/

本地预览仍需要网络连接，才能使用 AI 对话。

## 模型与安全架构

项目使用 DeepSeek 官方兼容 Chat Completions 接口，当前固定模型为：

    deepseek-v4-flash

请求链路如下：

    Android / 浏览器
            ↓
    GitHub Pages 静态前端
            ↓  HTTPS + Bearer API Key
    DeepSeek 官方 API

当前部署方式：

- 浏览器直接请求 DeepSeek 官方接口，不经过第三方代理；
- 国内网络不再依赖 chatgpt.site 服务；
- 为实现打开即用，DeepSeek API Key 按项目所有者要求内嵌在 index.html；
- 这是公开仓库，任何人都可能从源码中提取 Key 并消耗余额；
- 建议在 DeepSeek 控制台设置余额、调用量或告警，并定期检查用量；
- 如果页面被公开传播或出现异常用量，应立即更换 Key，并改为服务端代理。

## 技术实现

- 原生 HTML、CSS 和 JavaScript；
- 单文件响应式页面；
- Fetch API 直接调用 DeepSeek 官方 API；

## 部署与维护

修改页面后建议依次检查：

1. index.html 的 JavaScript 语法；
2. DeepSeek 接口地址和模型名称正确；
3. 普通 Pages 地址打开后能直接进入对话；
4. 主探索与人物卡片对话都能获得模型响应；
5. 生成说明书后标签页、继续追问和重新探索正常；
6. Android 竖屏下输入框、选项、卡片和报告没有横向溢出；
7. GitHub Pages 发布内容与仓库最新 index.html 一致。

项目当前同时同步 main 和 master 分支：main 是默认代码分支，master 用于现有 GitHub Pages 发布配置。更新页面时应保持两个分支的发布文件一致。

## 已知限制

- AI 功能必须联网；
- 模型输出具有随机性，同一回答可能得到不同措辞；
- 页面建议不是官方志愿填报结论；
- 招生计划、选科要求、专业名称和就业情况会变化；
- Google Fonts 等外部资源加载失败时会回退到系统字体。

## 志愿填报提示

在根据页面结果作出实际决定前，至少还应核对：

- 本省当年招生计划和志愿规则；
- 目标院校最新招生章程；
- 专业选科、体检、单科成绩和外语要求；
- 专业培养方案、核心课程、转专业政策和保研情况；
- 学费、城市、住宿、实习和就业去向；
- 自己的成绩区间、风险偏好和家庭条件。

## 版权与使用说明

本项目用于个人自我探索、志愿调研和前端展示。历史人物资料、字体及第三方服务应遵守各自的使用条款。页面生成内容仅供参考，不构成升学、就业或心理评估方面的专业意见。
