# Self Manual · 个人说明与 AI 实验记录

这是一个用于整理个人说明、工作方式和 DeepSeek API 实验记录的轻量仓库。

> 当前状态：资料型占位项目，暂未提供可运行的网页入口。  
> GitHub：[查看仓库](https://github.com/yusheng266186-beep/self-manual)

## 项目定位

self-manual 不以发布网站为当前目标，而是作为个人知识整理和 AI 实验的容器，未来可以逐步沉淀：

- 个人信息与工作偏好；
- 常用工具、流程和提示词；
- DeepSeek API 或其他模型接口的调用记录；
- 实验结果、复盘笔记和可复用模板；
- 面向未来项目的统一说明文档。

当前仓库内容很少，适合把它当成一个干净的起点，而不是已经完成的应用。

## API 安全要求

任何 API 实验都必须遵守：

1. 不要把 API Key 写进 README、网页源码或提交记录；
2. 不要把 .env、密钥文件和带密钥的日志推送到 GitHub；
3. 使用环境变量或本地密钥管理工具；
4. 提交前检查 git diff 和待提交文件；
5. 如果密钥曾经被提交，立即撤销并重新生成；
6. 公开实验时只保留脱敏后的请求、响应和统计信息。

示例代码中应使用占位符，例如：

    DEEPSEEK_API_KEY=replace-with-your-local-key

不要把真实密钥替换进去。
